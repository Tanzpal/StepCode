# StepCode Landing Page

A responsive React + Vite landing page inspired by the supplied Render reference. The hero's right side is intentionally empty, and the upper-left purple glow is created with CSS gradients.

## Run locally

```bash
npm install
npm run dev
```

## Structure

- `src/App.jsx` — component calls only
- `src/components/Navbar.jsx` + `Navbar.module.css`
- `src/components/ThemeToggle.jsx` + `ThemeToggle.module.css`
- `src/pages/LandingPage.jsx` + `LandingPage.module.css`
- `src/index.css` — global reset and font
- `src/assets/stepcode-logo.png` — recolored StepCode logo

The navigation and CTA links are placeholders; connect them to your actual pages/routes as needed.
